# Product Vision

WikiRace is a multiplayer Wikipedia bingo game.

Players navigate Wikipedia pages while attempting to complete bingo objectives.

The long-term vision is a streamer-friendly game similar to:

- GeoGuessr
- Neal.fun games
- SmallAnt challenge content
- Multiplayer bingo races

Core goals:

- Easy to join
- Fun to watch
- Fun to stream
- Supports teams and spectators
- Real-time updates
